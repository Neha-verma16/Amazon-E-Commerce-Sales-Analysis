# Amazon E-Commerce Sales Analysis 📊

## 📌 Project Overview
This project focuses on analyzing Amazon E-Commerce sales data using Microsoft Excel to identify sales trends, product performance, customer purchasing patterns, and business insights.

The objective is to transform raw sales data into meaningful information that supports better business decision-making.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization

## 📊 Key Analysis
- Sales Performance Analysis
- Product Category Analysis
- Customer Purchasing Patterns
- Order Analysis
- Revenue Analysis
- Sales Trends

## 🔍 Key Objectives
- Identify top-performing products and categories.
- Understand customer purchasing behaviour.
- Analyze sales and revenue patterns.
- Identify business trends and opportunities.
- Generate meaningful insights from raw data.

## 💡 Business Benefits
- Better understanding of sales performance.
- Identification of popular product categories.
- Improved business decision-making.
- Data-driven sales strategies.

## 🎯 Project Outcome
Created an Excel-based sales analysis to convert raw E-Commerce data into meaningful business insights through data cleaning, analysis, and visualization.
